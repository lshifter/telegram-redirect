Документация к сайту "Гран-при Нидерландов 2025"

Описание

Этот проект представляет собой высококачественный лендинг, посвященный гонке Формулы-1 в Нидерландах. Сайт создан с использованием современных веб-технологий и включает в себя множество интерактивных элементов для привлечения пользователей.

Основные функции

•
Адаптивный дизайн: Сайт полностью адаптирован для просмотра на различных устройствах, включая ПК, планшеты и смартфоны.

•
Интерактивные карточки гонщиков: Карточки с 3D-эффектом при наведении, содержащие информацию о гонщиках.

•
Анимированные кнопки поддержки: Кнопки с анимацией и переходом на целевую страницу.

•
Секция ставок: Возможность сделать ставку на "сейфти-кар" с отображением коэффициентов.

•
Всплывающее окно с трансляцией: Модальное окно с имитацией прямой трансляции, доступ к которой открывается после поддержки гонщика или ставки.

•
Плавные анимации и переходы: Использование CSS-анимаций для улучшения пользовательского опыта.

•
Подвал с контактами: В подвале сайта размещена ссылка на Telegram-канал.

Файловая структура

•
index_v2.html: Основной HTML-файл, содержащий структуру сайта.

•
styles_v2.css: CSS-файл со стилями и анимациями.

•
script_v2.js: JavaScript-файл, отвечающий за интерактивность и логику сайта.

Установка и запуск

Для запуска сайта достаточно открыть файл index_v2.html в любом современном веб-браузере.
